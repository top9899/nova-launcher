Как начать

  1. 1

    Скачай и установи

    Установщик для Windows занимает пару минут. Регистрация не нужна. Java нужна подходящая под версию игры: NOVA проверит её, но сама не установит.

  2. 2

    Введи никнейм

    Для офлайн-режима достаточно ника. Для онлайн-серверов может понадобиться аккаунт Microsoft.

  3. 3

    Нажми «Играть»

    Первый запуск версии займёт пару минут — NOVA скачает игровые файлы.
